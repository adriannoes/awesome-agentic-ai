## What is this

The community-maintained **list of OpenClaw derivatives** — 35+ AI agents inspired by or forked from OpenClaw across different languages (Rust, Go, TypeScript, Python, Zig, Crystal, C, Kotlin, …). Ranges from ultra-light embedded ports (MimiClaw on ESP32-S3, zclaw in C) to full-featured alternative runtimes (OpenFang at 137K LOC).

## Why vendored

The 35+ derivatives in this list are the fastest way to **find a fork that fits your constraints** — running on an ESP32? Use MimiClaw. Need Rust + strong sandboxing? ZeroClaw or Autobot. Privacy-first? IronClaw. The derivatives table in [../README.md](../README.md) is built from this index; we vendor the full upstream README as the authoritative snapshot in case `machinae/awesome-claws` is ever moved or deleted.

For the **latest additions**, see the upstream repo. Ours is a point-in-time copy.
