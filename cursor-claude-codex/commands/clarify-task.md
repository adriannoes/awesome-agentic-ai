# Clarify Task

## Overview

Break down ambiguous tasks into clear, actionable steps before implementation.

## Steps

1. **Identify ambiguity**
   - What is unclear or underspecified?
   - What assumptions might we be making?
   - What could go wrong if we guess wrong?

2. **Ask clarifying questions**
   - One question at a time
   - Prefer multiple choice when possible
   - Focus on: purpose, constraints, success criteria

3. **Present interpretations**
   - If multiple interpretations exist, list them
   - Don't pick silently — surface tradeoffs
   - Get explicit confirmation before proceeding

4. **Define acceptance criteria**
   - What does "done" look like?
   - How will we verify success?
   - What are the boundaries of scope?

5. **Produce actionable steps**
   - Ordered list of concrete steps
   - Each step has a clear verification
   - Share with user for approval before implementation

## Output

Deliver a brief task breakdown with:
- Clarified scope and constraints
- Explicit assumptions (or questions still open)
- Ordered steps with verification criteria
- User sign-off before coding
