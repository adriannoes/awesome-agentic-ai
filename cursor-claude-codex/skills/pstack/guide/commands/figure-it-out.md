# /figure-it-out

## When to use

No bundled playbook fits — large migrations, ambitious multi-part changes, or work a human reviews after you step away.

## Example prompt

```text
/figure-it-out migrate every caller from the sync store to the async one, keeping behavior identical.
```

## What you get back

A custom auditable playbook with hypothesis loop and decision logging via show-me-your-work.
