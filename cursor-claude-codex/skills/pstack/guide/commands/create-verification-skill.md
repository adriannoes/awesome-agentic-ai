# /create-verification-skill

## When to use

The project has no scripted way to prove app behavior the way a user would (any language or platform).

## Example prompt

```text
/create-verification-skill make a control skill for this repo so agents can verify UI changes.
```

## What you get back

A project-local verification skill with a feature map agents can drive headlessly.
