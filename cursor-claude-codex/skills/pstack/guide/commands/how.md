# /how

## When to use

Before changing code you do not fully understand: runtime flow, layering, ownership, or "where should this live?" questions.

## Example prompt

```text
/how do we cancel runs? do we have an n+1 when we look up every run to cancel?
```

## What you get back

An architectural walkthrough at senior-engineer onboarding depth — enough mental model to edit safely, not annotated source.
