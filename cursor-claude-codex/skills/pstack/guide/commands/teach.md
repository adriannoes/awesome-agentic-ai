# /teach

## When to use

You want to actually understand a change or subsystem, not just receive a summary.

## Example prompt

```text
/teach me this retry middleware — i need to understand it well enough to extend it.
```

## What you get back

Runs how + why and weaves findings into one plain explanation, built up diagram by diagram.
