# /why

## When to use

Design rationale, regressions, postmortems, or "why was it built this way?" when motivation matters more than runtime flow.

## Example prompt

```text
/why is this feature flag not on yet?
```

## What you get back

A cited read on decisions and tradeoffs. Queries available MCPs (git, issues, docs, chat, observability) in parallel when configured.
