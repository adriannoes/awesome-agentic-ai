# /reflect

## When to use

A long task finished and you want the recipe captured as concrete skill edits for the next run.

## Example prompt

```text
/reflect that took too long. capture what we learned so the next run does not repeat it.
```

## What you get back

Three parallel review subagents surface learnings routed to specific edits on existing skills.
