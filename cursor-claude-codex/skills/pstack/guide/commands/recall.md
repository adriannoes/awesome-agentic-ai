# /recall

## When to use

Starting or resuming work and you need recent context rebuilt from chat history and shared records.

## Example prompt

```text
/recall catch me up on the export retry work from last week.
```

## What you get back

A tight current-state brief: what you were doing, where you left off, and open threads.
