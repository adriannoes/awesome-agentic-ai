# /make-bot-ui

## When to use

Building a page or dashboard whose buttons wake a Grok Bot over a webhook, including Tailscale exposure.

## Example prompt

```text
/make-bot-ui build a dashboard with buttons that trigger my Grok Bot webhook.
```

## What you get back

A custom UI wired to webhook sender keys and Tailscale setup guidance.
