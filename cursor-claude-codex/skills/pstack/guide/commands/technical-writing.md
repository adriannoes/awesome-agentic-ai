# /technical-writing

## When to use

Writing or reviewing docs, RFCs, readmes, PR descriptions, or commit messages to a layered standard.

## Example prompt

```text
/technical-writing tighten this PR description before I open it.
```

## What you get back

Copy aligned with Diátaxis + Google developer style + STE + Global English.
