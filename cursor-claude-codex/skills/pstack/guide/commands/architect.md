# /architect

## When to use

Non-trivial work crossing a function boundary where jumping straight to code would lock in the wrong shape.

## Example prompt

```text
/architect design this instrumentation to be high signal with no false positives.
```

## What you get back

Types, signatures, and module structure settled before implementation, with the architect staying in the loop while code lands.
