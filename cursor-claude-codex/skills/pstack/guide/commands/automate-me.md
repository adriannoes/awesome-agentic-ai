# /automate-me

## When to use

You want a personal `-mode` skill drafted from how you actually work, routing through pstack underneath.

## Example prompt

```text
/automate-me
```

## What you get back

A draft or refresh of your custom mode skill via create-skill + unslop, optionally mined from recent transcripts.
