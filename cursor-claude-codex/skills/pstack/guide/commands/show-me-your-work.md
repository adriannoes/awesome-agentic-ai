# /show-me-your-work

## When to use

Long-running, autonomous, or multi-phase work where a reviewer needs a decision trail they can audit.

## Example prompt

```text
/show-me-your-work keep a decision trail i can review when i am back.
```

## What you get back

A TSV log with one row per decision (what, why, evidence, result). Commit it when a reviewer needs the trail.
