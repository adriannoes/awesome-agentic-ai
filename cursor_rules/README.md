# Cursor Rules

Optimized Cursor configurations to speed up your development workflow. These rules help you:
- Generate more accurate code
- Maintain consistent patterns
- Reduce back-and-forth with the AI
- Focus on the important stuff

## How to Use

1. Copy the rules you need
2. Add them to your `.cursorrules` file
3. Customize based on your project
4. Test and iterate

## Rule Categories

### 🎯 **Project-Specific Rules**
- React/Next.js development

- Full-stack applications

### 🔧 **General Development**
- Code style and formatting
- Error handling patterns
- Testing requirements

### 🚀 **AI-Assisted Development**
- Prompt optimization
