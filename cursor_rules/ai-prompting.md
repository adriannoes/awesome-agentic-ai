# AI Prompting Rules

Use these rules when working with AI models and prompt engineering.

## Prompt Structure
- Start with clear context and role
- Provide specific examples
- Use step-by-step instructions
- Include expected output format

## Code Generation
- Specify the programming language and framework
- Include relevant imports and dependencies
- Ask for error handling and validation
- Request comments and documentation

## Debugging Prompts
- Provide the full error message
- Include relevant code context
- Specify the expected behavior
- Ask for multiple solution approaches

## Example Prompt Template
```
You are an expert [ROLE] working with [TECHNOLOGY].

Task: [SPECIFIC_TASK]

Requirements:
- [REQUIREMENT_1]
- [REQUIREMENT_2]
- [REQUIREMENT_3]

Example:
[RELEVANT_EXAMPLE]

Please provide:
1. [OUTPUT_1]
2. [OUTPUT_2]
3. [OUTPUT_3]
```
