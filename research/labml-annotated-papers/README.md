# labml.ai annotated paper implementations (link-only)

**Source:** [labmlai/annotated_deep_learning_paper_implementations](https://github.com/labmlai/annotated_deep_learning_paper_implementations)
**License:** MIT
**Site:** [nn.labml.ai](https://nn.labml.ai/index.html) — side-by-side code and explanations (primary reading experience)

## What it is

**60+** actively maintained PyTorch implementations of deep learning papers with inline documentation: transformers (GPT, ViT, Switch, RETRO, RoPE, …), optimizers (Adam, Sophia, …), GANs, diffusion-adjacent models, RL (PPO, DQN), distillation, and more. This hub does **not** mirror the Python tree (~too large and fast-moving); clone upstream or browse the website.

```bash
git clone https://github.com/labmlai/annotated_deep_learning_paper_implementations.git
pip install -r requirements.txt
# Browse https://nn.labml.ai for rendered notes
```
