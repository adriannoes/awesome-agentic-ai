# Prompt Experiments

This folder contains experimental prompts and their results. Each experiment includes:
- The original prompt
- Test cases used
- Results and analysis
- Lessons learned

## Experiment Structure

```
experiment-name/
├── prompt.md              # The prompt being tested
├── test-cases.md          # Input/output examples
├── results.md             # Analysis and findings
└── README.md              # Summary and conclusions
```

## Current Experiments

- **Code Generation Quality**: Comparing different prompt styles for generating React components
- **Error Handling**: Testing prompts for debugging and error resolution
- **Documentation**: Evaluating prompts for generating clear, useful docs
- **Refactoring**: Testing prompts for code improvement suggestions

## Running Your Own Experiments

1. Create a new folder with a descriptive name
2. Add your prompt and test cases
3. Document your results
4. Share your findings!

## Guidelines

- Be specific about what you're testing
- Include multiple test cases
- Document both successes and failures
- Explain what you learned
- Suggest improvements
