# Datasets

Small, curated datasets for learning and experimentation. Each dataset includes:
- Clear description
- Usage examples
- Data format documentation
- Suggested applications

## 📊 **Available Datasets**

### **Sample Data**
- **User Behavior**: Simulated user interactions
- **Product Catalog**: E-commerce product data
- **Sales Data**: Time series sales information
- **Text Data**: Sample documents for NLP

### **Reference Data**
- **API Examples**: Sample API responses
- **Configuration**: Common config files
- **Templates**: Data structure templates

## 🚀 **Using the Datasets**

Most datasets are in JSON or CSV format:
```python
import pandas as pd
df = pd.read_csv('datasets/sales-data.csv')
```

## 📝 **Dataset Guidelines**

- **Size**: Keep datasets small (< 10MB)
- **Format**: Use standard formats (CSV, JSON, Parquet)
- **Documentation**: Include clear descriptions
- **Privacy**: No real personal data
