# VibeCoding Hub

> Where Product Managers and Designers learn to code with AI, understand what's happening under the hood, and ship real products.

This is your go-to resource for bridging the gap between product thinking and technical execution. Whether you're a PM who wants to prototype faster or a Designer who wants to understand the code your AI is generating, this repo has everything you need to level up your technical skills.

## What You'll Find Here

### 🚀 **Ready-to-Use Projects**
Clone and run projects built with modern AI tools:
- **Lovable** apps with full-stack TypeScript
- **v0.dev** components and pages
- **Bolt** rapid prototypes
- Complete examples showing the full 0→1 journey

### 🧠 **Learning Resources**
- Curated courses on Python, TypeScript, and AI fundamentals
- Video recommendations and book notes
- Tutorials that explain the "why" behind the code
- Practical guides for non-technical folks

### ⚡ **Cursor Rules & Prompts**
- Optimized Cursor configurations for faster development
- Battle-tested prompts for different scenarios
- Template libraries for common tasks
- Prompt engineering techniques that actually work

### 🔬 **Experiments & Notebooks**
- Reproducible AI experiments
- Jupyter notebooks with clear explanations
- Model comparisons and benchmarks
- Real-world case studies

## Quick Start

1. **Clone this repo**
   ```bash
   git clone https://github.com/yourusername/vibecoding-hub.git
   cd vibecoding-hub
   ```

2. **Pick a project and run it**
   ```bash
   cd examples/your-chosen-project
   npm install  # or pip install -r requirements.txt
   npm run dev  # or python app.py
   ```

3. **Start learning**
   - Check out `learning/` for structured courses
   - Browse `prompts/` for ready-to-use templates
   - Explore `notebooks/` for hands-on experiments
